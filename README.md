# ASZEEL COMPUTER - Store & Service Management System

Aplikasi manajemen toko dan pelayanan jasa untuk **ASZEEL COMPUTER**.

## Fitur Utama
- Katalog Produk (Laptop, Printer, PC, Sparepart)
- Pelacakan Status Servis (Laptop/Printer/PC)
- Kalkulator & Pemesanan Jasa Cetak (Print, Foto, Undangan, Fotokopi)
- Transaksi POS & Pencatatan Penjualan

## Tech Stack
- PHP, HTML5, CSS3, JavaScript
- MySQL
